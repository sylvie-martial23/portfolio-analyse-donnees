
# Portfolio en analyse de données

Bienvenue sur mon portfolio !

Je construis progressivement mes compétences en analyse de données à travers des projets pratiques et des études de cas.

## À propos

Titulaire d'une Licence en économie internationale et formée en analyse de données, je développe mes compétences pour mieux exploiter les données, comprendre les problèmes et aider à la prise de décision.

## Outils étudiés

- Excel : nettoyage, analyse et visualisation des données
- SQL : interrogation et analyse de bases de données
- Python : préparation, exploration et analyse des données
- Power BI : création de tableaux de bord interactifs

## Mes projets

Les projets seront ajoutés progressivement au fil de ma formation. Ils porteront notamment sur l'analyse commerciale et financière, la performance des activités et les données liées au développement.

## Objectif

Construire un portfolio présentant mes méthodes de travail, mes analyses, mes résultats et les enseignements tirés de chaque projet.
